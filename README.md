# C-SAGE

**Cloud Security, Audit, Governance & Evidence**

C-SAGE is a multi-cloud compliance grid application for banking cloud environments. It provides a unified view of compliance posture, resource inventory, findings, remediation status, and audit evidence across AWS, Azure, GCP, and OCI.

## UI Standard

The application follows the ICICI Bank Digital Platform UI Standard v2.4 supplied for this project, including:

- Corporate Orange `#F37021`
- Deep Navy `#003366`
- Roboto / Helvetica Neue / Arial typography
- High-contrast, accessibility-first enterprise layouts
- Card and grid based compliance visualization
- Clear status and remediation indicators

## Initial Modules

- Executive compliance dashboard
- Multi-cloud compliance grid
- AWS / Azure / GCP / OCI posture summary
- Resource inventory
- Compliance findings and severity
- Audit evidence readiness
- Remediation tracking
- RBI-oriented compliance overview

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
